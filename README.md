# Scalable Central Document Management System (DMS)

A cloud-native, scalable, and permission-safe Document Management System for public-authority document archiving.

The system enables public authorities to upload, organize, search, and manage digital documents through a shared platform secured by role-based access control (RBAC), powered by full-text search with OCR support, and deployed on Kubernetes.

**Core technologies:** MongoDB for storage, Keycloak for authentication, Docker Compose for development, Kubernetes + Gitea for production deployment.
